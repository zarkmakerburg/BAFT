# ۱ — نصب

[فهرست راهنما](README.md) · [English](../../en/guide/01-install.md)

## پیش‌نیازها

- دو سرور با Debian یا Ubuntu (amd64 یا arm64): یکی **خارج از ایران** (همان‌جا که x-ui هست) و یکی **داخل ایران**.
- دسترسی root روی هر دو (`sudo -i`).
- اگر می‌خواهید نصب‌کننده سرور ایران را خودش راه بیندازد: دسترسی SSH از سرور خارج به سرور ایران (کاربر root یا کاربری با `sudo` بدون رمز)، با رمز یا کلید.
- برای پنل با SSL: دامنه‌ای که به سرور اشاره کند یا فقط IP عمومی سرور، و آزاد بودن پورت ۸۰ هنگام گرفتن گواهی.

## قدم ۱: سرور خارج

با دسترسی root اجرا کنید:

<div dir="ltr" align="left">

```bash
bash <(curl -Ls https://raw.githubusercontent.com/zarkmakerburg/baft/main/install.sh)
```

</div>

گزینهٔ **۱ (خارج از ایران)** را انتخاب کنید. نصب‌کننده این کارها را می‌کند:

1. سیستم را بررسی می‌کند، نسخهٔ امضاشده را دانلود می‌کند و آن را با کلید ریشهٔ ثبت‌شده **وارسی** می‌کند (نسخهٔ وارسی‌نشده یا قدیمی‌تر رد می‌شود)؛
2. آدرس عمومی همین سرور را می‌پرسد (آدرس تشخیص‌داده‌شده پیش‌فرض است)؛
3. می‌پرسد کدام **پورت‌ها باید عبور کنند**. پورت‌هایی را که سرور الان روی آن‌ها گوش می‌دهد (مثل inboundهای x-ui) پیشنهاد می‌کند. آن‌ها را با ویرگول جدا کنید، مثلاً `443,2053`؛
4. می‌پرسد سرور ایران چطور راه بیفتد: **با SSH از همین‌جا** (پیشنهادی) یا دستی با کد جفت‌شدن؛
5. پیش از جفت‌شدن **مسیر ایران به خارج را تست می‌کند** تا زود بفهمید دیتاسنتر ایرانی شما اتصال به خارج را قطع می‌کند یا نه؛
6. دو سرور را جفت می‌کند و تونل را راه می‌اندازد؛
7. پیشنهاد می‌دهد **پنل وب** را هم روی همین سرور نصب کند (دامنه یا IP، با گواهی Let's Encrypt)؛ ببینید [پنل](03-panel.md)؛
8. پیشنهاد می‌دهد **BBR** و تنظیمات TCP را روشن کند؛ ببینید [شبکه و BBR](04-network-and-bbr.md).

صفحهٔ آخر لینک پنل، نام کاربری و یک رمز یک‌بارنمایش را نشان می‌دهد. رمز را همان موقع ذخیره کنید؛ دوباره نمایش داده نمی‌شود (با `sudo baft-panel` می‌توانید ورود تازه بسازید).

## قدم ۲: سرور ایران

### روش الف: با SSH از سرور خارج (پیشنهادی)

`user@host` سرور ایران (و اگر پورت SSH غیر از ۲۲ است، پورت را) به‌همراه رمز یا کلید بدهید. نصب‌کننده اثر انگشت کلید میزبان SSH سرور ایران را نشان می‌دهد تا تأیید کنید، بعد آن را نصب و جفت می‌کند. لازم نیست وارد سرور ایران شوید، و سرور ایران هم لازم ندارد به گیت‌هاب وصل شود (که از ایران اغلب بسته است).

رمز یا کلید SSH فقط برای همین مرحله استفاده می‌شود و جایی ذخیره نمی‌شود.

### روش ب: دستی با کد جفت‌شدن

سرور خارج یک کد یک‌بارمصرف با پیشوند `BAFTPAIR1:` چاپ می‌کند و منتظر می‌ماند. روی سرور ایران همان خط نصب را اجرا کنید، گزینهٔ **۲ (داخل ایران)** را بزنید و کد را وارد کنید. سرور ایران یک کد پاسخ با پیشوند `BAFTREPLY1:` چاپ می‌کند؛ آن را در سرور خارج وارد کنید.

کد جفت‌شدن فقط **۱۵ دقیقه** و فقط یک بار معتبر است. اگر منقضی شد، [عیب‌یابی](06-troubleshooting.md#pairing-expired) را ببینید.

اگر سرور ایران نمی‌تواند از گیت‌هاب دانلود کند، از روش الف یا [نصب آفلاین](#offline-install) استفاده کنید.

## بررسی درستی کار

<div dir="ltr" align="left">

```bash
baft            # status menu
baft doctor     # full health check
baft version    # installed version
```

</div>

روی سرور ایران، خروجی `ss -ltn` باید پورت‌های عبوری را در حال گوش‌دادن نشان دهد. بعد سراغ [استفاده با x-ui](02-use-with-x-ui.md) بروید.

## اسکریپت و خودکارسازی

به همهٔ پرسش‌ها می‌شود با پارامتر جواب داد (اول نصب‌کننده را دانلود کنید):

<div dir="ltr" align="left">

```bash
curl -fsSLO https://raw.githubusercontent.com/zarkmakerburg/baft/main/install.sh
less install.sh     # read it first if you like
sudo bash install.sh --role ex --public-address EX_IP --ports 443,2053 \
  --ir-ssh root@IR_IP --ir-ssh-key /root/.ssh/id_ed25519 \
  --ir-ssh-fingerprint SHA256:... --with-panel
```

</div>

پارامترهای پرکاربرد: `--role ex|ir`، `--public-address`، `--ports`، `--pairing-code 'BAFTPAIR1:...'` (برای سرور ایران)، `--ir-ssh`، `--ir-ssh-key`، `--ir-ssh-fingerprint` (بدون ترمینال الزامی است)، `--with-panel` یا `--no-panel`، `--bcc-domain`، `--bcc-port`، `--version vX.Y.Z`، `--plan` (فقط نشان می‌دهد چه چیزی عوض می‌شود و چیزی را تغییر نمی‌دهد) و `--yes`. بدون ترمینال (یا با `BAFT_NONINTERACTIVE=1`) چیزی پرسیده نمی‌شود و `--role` الزامی است. `BAFT_TUNE_NETWORK=1` بدون پرسیدن BBR را روشن می‌کند. فهرست کامل: `bash install.sh --help`.

## نصب آفلاین

برای سروری که به گیت‌هاب دسترسی ندارد، هر نسخه یک بستهٔ `baft-offline-<version>.tar.gz` دارد. آن را به سرور منتقل کنید و بعد:

<div dir="ltr" align="left">

```bash
sha256sum -c baft-offline-vX.Y.Z.tar.gz.sha256
tar -xzf baft-offline-vX.Y.Z.tar.gz && cd baft-offline-vX.Y.Z
sudo bash install.sh --offline . --role ir --pairing-code 'BAFTPAIR1:...'
```

</div>

`--offline` از شبکه و `apt` استفاده نمی‌کند؛ `python3`، `openssl` و `sha256sum` باید از قبل نصب باشند. نسخهٔ داخل بسته دقیقاً مثل نصب آنلاین وارسی می‌شود. ببینید: [نسخه‌های امضاشده](../23-p1a-signed-releases.md).

## اضافه کردن سرور خارج دوم به سرور ایرانی که BAFT دارد

یک سرور ایران می‌تواند به چند سرور خارج وصل باشد. هر تونل سرویس، پوشه و پورت‌های محلی خودش را دارد و تونل قبلی دست نمی‌خورد.

- **با SSH از سرور خارج جدید:** کافی است نصب را روی سرور خارج جدید اجرا کنید و «Over SSH» را بزنید. سرور ایران خودش تشخیص می‌دهد که قبلاً جفت شده و تونل جدید را جدا می‌سازد.
- **دستی:** روی سرور ایران همان خط نصب را اجرا کنید. می‌پرسد «BAFT already runs a tunnel on this server»؛ گزینهٔ ۱ (Add another tunnel) را بزنید و کد جفت‌شدن را بدهید. اگر کد را از اول در دستور بدهید، بدون سؤال تونل جدا ساخته می‌شود:

<div dir="ltr" align="left">

```bash
curl -Ls https://raw.githubusercontent.com/zarkmakerburg/baft/main/install.sh | sudo bash -s -- --role ir --pairing-code 'BAFTPAIR1:...'
```

</div>

تونل دوم سرویس `baft-2` با پوشه‌های `/etc/baft-2` و `/var/lib/baft-2` است (و بعدی‌ها `baft-3`، `baft-4` و همین‌طور تا هر تعداد؛ سقفی ندارد). با `--instance NAME` می‌توانید اسم را خودتان بدهید. پورت‌هایی که سرور ایران عمومی سرو می‌کند نباید بین دو تونل تکراری باشند؛ اگر باشند نصب‌کننده هشدار می‌دهد. برای حذف یک تونل اضافه: `sudo systemctl disable --now baft-2` و بعد پوشه‌های آن و فایل `/etc/systemd/system/baft-2.service` را پاک کنید.

## اجرای دوبارهٔ نصب‌کننده

اجرای دوبارهٔ همان خط بی‌خطر است: سرور را بررسی می‌کند، برنامهٔ تغییرات را نشان می‌دهد، فقط همان‌ها را تغییر می‌دهد و اگر خطا بخورد برمی‌گرداند. هیچ‌وقت خودسرانه کلیدها را عوض نمی‌کند یا دوباره جفت نمی‌کند. ببینید: [به‌روزرسانی، پشتیبان و حذف](05-update-backup-uninstall.md) و [نصب‌کنندهٔ قابل اجرای مجدد](../33-rerunnable-installer.md).

جزئیات بیشتر: [اجرای IR و EX](../06-running-ir-ex.md)، [راه‌اندازی با SSH](../26-p1d-ssh-bootstrap.md).
