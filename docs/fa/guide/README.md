# راهنمای کاربر بافت

[English](../../en/guide/README.md) · [صفحهٔ اول](../../../README.fa.md) · [مستندات فنی](../README.md)

این راهنما برای کسی است که روی سرور خارج x-ui یا 3x-ui (یا سرویس TCP دیگری) دارد و می‌خواهد کاربرانش از داخل ایران، از طریق یک سرور ایران به آن وصل شوند. بار اول صفحه‌ها را به ترتیب بخوانید.

|---|---|---|
| ۱ | [نصب](01-install.md) | اول سرور خارج، بعد سرور ایران با SSH یا کد جفت‌شدن، نصب آفلاین |
| ۲ | [استفاده با x-ui](02-use-with-x-ui.md) | پورت‌های عبوری، تغییر لینک کاربران، چه کار می‌کند و چه نمی‌کند |
| ۳ | [پنل](03-panel.md) | پنل وب (BCC): دامنه یا IP، SSL، ورود، افزودن سرور |
| ۴ | [شبکه و BBR](04-network-and-bbr.md) | `sudo baft-net`: BBR، تست سرعت، مسیر و پورت |
| ۵ | [به‌روزرسانی، پشتیبان و حذف](05-update-backup-uninstall.md) | اجرای دوبارهٔ نصب‌کننده، پشتیبان پنل، حذف امن |
| ۶ | [عیب‌یابی](06-troubleshooting.md) | SSL، بسته‌بودن گیت‌هاب، کد منقضی، قطع اتصال، در دسترس نبودن پنل، لاگ‌ها |
| ۷ | [پرسش‌های رایج](07-faq.md) | جواب‌های کوتاه |

واژه‌هایی که در این راهنما می‌بینید:

- **سرور خارج** (EX): سروری که بیرون از ایران است و x-ui روی آن اجرا می‌شود.
- **سرور ایران** (IR): سروری داخل ایران که کاربران به آن وصل می‌شوند.
- **پنل** (BCC یا BAFT Command Center): پنل وب اختیاری؛ معمولاً روی سرور خارج.
- **پورت عبوری**: پورتی که سرور ایران روی آن گوش می‌دهد و به همان پورت روی سرور خارج می‌فرستد.

بافت تازه است و هنوز در میدان و در مقیاس بزرگ ثابت نشده است. ببینید: [محدودیت‌های شناخته‌شده](../../../KNOWN-LIMITATIONS.md).
